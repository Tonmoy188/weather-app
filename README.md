# Weather App 🌤️

## 🚀 Live Demo
[Click here to try the live demo](https://tonmoy188.github.io/weather-app/)

A sleek, real-time weather application built with vanilla JavaScript and the OpenWeatherMap API. This project demonstrates core JavaScript concepts including async/await, DOM manipulation, API integration, and dynamic UI rendering with a modern glassmorphism design.

## Features

* Real-time weather data with temperature, humidity, and wind speed
* Dynamic background gradients based on weather conditions
* Animated weather icons and smooth UI transitions
* Error handling for invalid cities and API issues
* Fully responsive glassmorphism design

## Key Functions & Technical Implementation

* **fetchWeather()** — Handles API calls to OpenWeatherMap, validates responses, and manages error states.
* **displayWeatherData()** — Dynamically updates DOM elements with weather information and updates the weather icon class.
* **updateBackground()** — Changes gradient backgrounds based on weather conditions using a condition-to-color mapping object.
* **Event Listeners** — Supports both button click and Enter key for seamless user interaction.

## Technologies Used

* HTML5, CSS3, Vanilla JavaScript (ES6+), OpenWeatherMap API
